# Fortune Table

Three exciting mini-games for your tabletop RPG sessions!

## 🎡 Wheel of Fortune (Roleta)
Spin a customizable wheel with animated segments. The GM can configure the items on the wheel — perfect for random encounters, loot tables, or dramatic story decisions.

## 🎰 Slot Machine (Caça-níquel)
Pull the lever and watch three reels spin! The GM secretly controls the win probability, creating moments of tension and excitement. Players never see the odds.

## 🪙 Coin Flip (Cara ou Coroa)
A classic coin flip with a satisfying 3D animation. Quick decisions made fun!

### Features
- **Synchronized**: All players see the same result in real-time
- **GM Controls**: Only the GM can access advanced settings
- **Everyone Plays**: Both GM and players can use all three games
- **Beautiful Animations**: Smooth, satisfying animations for every game
- **No Dependencies**: Lightweight, fast-loading vanilla JS

### How to Use
1. Click the Fortune Table icon in the action bar
2. Choose a mini-game tab
3. Click the action button to play
4. All players see the result!

**GM Tip**: Use the wheel for random encounters, the slot machine for treasure rolls, and the coin flip for quick yes/no decisions.
